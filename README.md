# cs300

what was the problem you were solving for this course?

Throughout the course we have learned about different data structures and the algorithms that allow us to use and manipulate the data held within. The example we were given was to store and provide information from a course list. 

How did you approach the problem?

To solve the problem given to us in the course we developed a similar starter program to test and check similar functions on lists, hash tables and binary search trees. After this I performed a runtime analysis on my algorithms to check the speed at which they ran.

how did you approach any roadblocks you encountered?
Whenever i was getting stuck on something i would reference the psuedocode and examples provided in the zybooks lessons. When this wasn't enough to help me overcome my issue i would look up videos on youtube to help further explain the topic.

How has your work on this project expanded my approach to designing software?

This course has expanded my view on how to handle data when efficiency is inversely effected by the size. Performing runtime analysis on different data structures shows how not using the right data structures to store and access information can hinder performance greatly.
